# 🏧 ATM人 (ATM Operator)

在 3 分鐘內扮演 ATM 機器裡的「人」，全手動核對卡片、密碼、餘額並點鈔出鈔。沒有防呆，錯誤全部變成損失、客訴或社會新聞！

## 玩法
1. **內部機房**：卡片插反（灰色背面）→ 將卡片**往上滑**推回；正面則記下卡號。
2. **終端機**：輸入卡號 →【查詢卡號】取得密碼與餘額。
3. 比對監視器上的密碼：正確按 **V**、錯誤按 **X**；連錯 3 次要按【鎖卡】。
4. 比對提款金額：餘額不足 → 上滑推回卡片；足夠 → 終端機輸入金額按【提款授權】，再到機房點鈔【確認出鈔】。

## 本機執行
```
python -m http.server 8000
```
開啟 http://localhost:8000 （建議使用手機或瀏覽器的手機模擬模式）。

## 部署到 GitHub Pages
1. 將本資料夾推送到 GitHub repository。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
3. 稍等片刻即可透過 `https://<帳號>.github.io/<repo>/` 遊玩。
